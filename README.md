# someday

An all-encompassing travel lifecycle app.

Fill out your travel profile, and a 3D globe lights up with personalized recommendations for where to go next. Mark countries visited, keep journals and photos, and watch your world grow.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run lint` | Lint with ESLint |
| `npm run format` | Format with Prettier |
| `npm test` | Run unit tests (Vitest) |
